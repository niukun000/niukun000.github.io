Receipt Scanner

iOS app · 2026

Source code →

Scan a receipt with the camera, pick one from Photos, or import a PDF. The app reads it with Apple Vision text recognition, pulls out the store, date, items and totals, saves it with SwiftData, and charts spending over time with Swift Charts.

What's interesting

Tilted receipts still parse

OCR text is grouped into rows by position and angle, so a crooked photo doesn't scramble item names and prices.

On-device AI, with a safety check

When items don't add up to the printed subtotal, Apple's on-device Foundation Models suggests moving misplaced prices between lines. A fix is kept only if the re-parsed receipt balances; otherwise the user reviews it.

Concurrency done properly

Scanning runs in a Swift actor behind a Sendable protocol, and the UI state lives in a @MainActor @Observable view model.

Testable by design

Dependencies are injected through protocols, so tests swap in fakes. Parser tests run against real receipt scans.

31 ms → ~0date extraction after profiling

XCUITest flows cover scanning, history, detail, delete, and spending summaries using seeded test data, plus a contrast accessibility audit. Instruments Time Profiler showed the date detector and regexes were rebuilt on every call; caching them cut date extraction from 31 ms to below the profiler's threshold, so the whole parser now costs less than that one lookup did.
